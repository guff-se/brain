Förlåt, Syed Latif. Förlåt för att du på tisdagsmorgonen klockan 08:00 måste infinna dig på Migrationsverket i Malmö för vidare transport till Kastrup. Förlåt för att du fått köpa en enkelbiljett till Bangladesh. Förlåt för att det svenska systemet sagt till dig att dina sex år i Sverige där du bekostat din egen utbildning, där du drivit flera integrationsprojekt och där du engagerat dig för ditt nya hemland, inte är något värt. Förlåt för att vi tagit dig för given och förlåt för att Sverige säger att du trots att du gjort allting rätt, inte räcker till. Förlåt för att du måste lämna ditt hem, dina vänner, ditt jobb och ditt liv. Förlåt för att vi utvisar dig för att du sökte och fick ett jobb via fel digital plattform.
Förlåt för att Migrationsdomstolen begått en grov feltolkning av lagstiftningen. Förlåt för att du inte får uppehållstillstånd. Förlåt för att varken Kammarrätten eller Högsta förvaltningsdomstolen var intresserade av att stoppa det justitiemord som nu begås. Förlåt för det du nu får gå igenom. Förlåt för att det inte lönar sig att vara självständig i landet lagom. Förlåt för att en statlig arbetsförmedlare ges större värde än en privat.
Förlåt för att Sverige gav dig hopp. Förlåt för att vi applåderade dig för dina sociala insatser och dina nätverkande initiativ, men inte värdesatte dem tillräckligt högt för att kunna göra undantag. Förlåt för att de nyanlända som går på det språkcafé du startat upp i Skurup nu får se den svenska byråkratins brutalism och att ditt fall nu skapar oro och rädsla för att göra fel så att de också kanske kastas ut. Förlåt för att de kanske inte vågar söka några jobb utan hellre stannar i bidragsberoende.
Förlåt för att vi gjort det omöjligt för dig att stanna. Förlåt för att vi lägger större vikt vid hur du fick ditt jobb, än att du fick det. Förlåt för att vi i Sverige är mer intresserade av att bygga system, än att låta människor bygga sina egna liv.
Förlåt för att vi sänder mixade signaler om att vara det mest liberala och öppna landet i världen. Förlåt för att vi hellre ser att våra invandrare går på kurser och tar emot bidrag och är segregerade än initiativrika och självständiga.
Förlåt för att vår justitieminister Morgan Johansson (S) inte hinner svara på den interpellation som C-riksdagsledamoten Annika Qarlsson ställt, innan du utvisas. Förlåt för att lagstiftningen från 2008 redan är en utdöd dinosaurie.
Förlåt för att din arbetsgivare hade höga ambitioner med tillsättningen och därmed annonserade på LinkedIn och inte på Arbetsförmedlingens egen sida. Förlåt för att protektionism verkar vara viktigare än frihet. Förlåt för att vi tvingas be om ursäkt.
Förlåt för att du inte kommer vara den sista som riskerar att utvisas för att de sökte och fick ett jobb via fel plattform. Förlåt för att den svenska byråkratin i sina sämsta, mörkaste stunder bryter ner människor i stället för att bygga upp dem. Förlåt för att vi gjort dig liten. Förlåt för att du nu måste starta om i Bangladesh. Förlåt för allt vi tar ifrån dig. Förlåt för att vi gav dig ett språk så att du kunde lära nyanlända hur man säger "hej då".
Förlåt för allt. Förlåt.
