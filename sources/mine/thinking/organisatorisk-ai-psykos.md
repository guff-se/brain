Ja, AI kommer göra att vi ersätter arbeten som vi gör och därför kommer ersätta arbetsuppgifter och anställda som vi har. Men på grund av att vi kan göra saker mycket billigare så finns det också väldigt många nya saker som vi kan göra som vi inte tidigare hade råd att göra. Så vi kommer också börja köra fler saker, ta fler initiativ, bygga fler produkter, hitta på fler appar som vi inte tidigare hade... Det var inte värt att göra för att startupkostnaden för det initiativet var så högt.

Problemet är att det kommer bli som ett organisatoriskt-produktutvecklings-mellandagsrea, där vi kommer köpa massa saker, bygga massa saker som vi faktiskt inte behöver, för att det är så billigt och för att vi får så mycket beröm från AI för att vi varit så duktiga och byggt just den här grejen.
