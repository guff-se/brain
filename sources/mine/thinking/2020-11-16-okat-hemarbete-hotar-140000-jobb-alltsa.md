"Ökat hemarbete hotar 140.000 jobb."
Alltså, att vi jobbar hemifrån gör att vi inte lunchar så mycket på stan, reser lika mycket, och gör färre "sällanköp i stora köpcenter".
Så vi måste gå tillbaka till våra arbetsplatser! Inte för att vi behöver det för att må bättre, eller att våra arbetsgivare behöver det för att vi skall göra ett bättre jobb, utan för att andra skall kunna jobba med att ta hand om oss medan vi är där!

Tänk hur skulle framtiden se ut om vi inte har några "sällanköp i stora köpcenter"! 😱😱😱
