# Session 2026-06-16-1130 — guff.se blog import

## Request
Import all posts from the old blog at https://guff.se/en/blog/ into the vault:
write a scraper, then run LLM ingest on each post.

## What came in
- Crawled `https://guff.se/en/blog/` (3 pages of pagination) → **25 posts** (2008–2020).
- These are Gustaf's OWN published posts → classified `party: first`, `register: voice`
  (not the generic `inbox/articles → consumed` path). Mostly Swedish, entrepreneurship-era
  (Entreprenörsjakten / YEOS, 2008–2012) plus one 2012 futurism piece and one autobiographical
  post on being "särbegåvad".

## Tools written
- `_ai/scripts/scrape_blog.py` — crawls all `/blog/page/N/` pages, downloads each post,
  extracts title/date/body (pandoc HTML→Markdown), stages to `_ai/import/guff-blog/<YYYY-MM-slug>.md`,
  and flags likely duplicates of existing `sources/mine/voice/` notes. Re-runnable.
- `_ai/scripts/ingest_blog.py` — reads the scrape manifest + an agent-authored
  `_ingest_plan.json` (summary/tags/dupe/skip decisions), assembles voice notes
  (frontmatter + **verbatim** body), enriches dupes, updates `.manifest.json`, clears staging.
  `--apply` to write, dry-run by default.

## What was produced
- **20 new voice notes** in `sources/mine/voice/` (`YYYY-MM-DD-slug.md`), full frontmatter,
  bodies untouched. All tags drawn from existing `_meta/taxonomy.md` — no new tags needed.
- **4 enriched**: posts that already existed as Evernote-sourced voice notes got `url:` added
  to frontmatter; bodies left untouched (no-rewrite-voice rule). Flagged for review — the
  scraped published versions are richer (see review queue).
- **1 skipped**: `hello-world` (WordPress placeholder). Flagged for review.
- `.manifest.json`: appended ingestion record (`scope: guff.se blog import`).
